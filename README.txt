Single-Cycle 32-bit RISC-V CPU
  A fully functional RV32I-compatible CPU implemented in Verilog for educational purposes. This project was developed as part of a university project.
This is a single-cycle RISC-V processor implementing the RV32I base integer instruction set. The design emphasizes clarity, modularity, and correctness over performance optimization. All major components from instruction fetch to write-back are implemented as separate Verilog modules and integrated into a clean, understandable datapath.

Future Work
  This CPU can be extended in several ways:
-Pipeling
-Caches
-Additional instruction support
-A compiler
